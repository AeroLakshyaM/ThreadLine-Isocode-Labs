# Handover checklist

- [ ] Confirm Company A identity and customer data owner.
- [ ] Approve real buyer, unit, line, user and stage/TNA records.
- [ ] Approve work calendar and risk thresholds; keep risk labels insufficient until approval.
- [ ] Confirm hosting region, retention, backups, restore owner and incident response.
- [ ] Create Supabase staging and production projects; apply reviewed migration.
- [ ] Configure RLS and test buyer A/B isolation and supervisor stage boundaries.
- [ ] Configure exact `APP_ORIGIN`, Edge Function secrets and provider keys only after consent.
- [ ] Validate the photo review/approval screen and signed URL behavior in staging.
- [ ] Pilot Tamil audio with representative recordings and human reviewers; approve provider/data terms.
- [ ] Validate report content, buyer-visible photos/remarks and archival requirements.
- [ ] Test offline queue and media retry on target low-end Android devices.
- [ ] Resolve dependency advisories and review bundle size.
- [ ] Configure monitoring, error logging, alerts and scheduled backups.
- [ ] Run and record every acceptance case, including security denial cases.
- [ ] Train administrator, merchandisers, supervisors and buyers.
- [ ] Confirm launch owner, rollback plan and support contact.
